# Mobile responsive updates

The responsive stylesheet now includes layouts for:
- Small phones (320px–380px)
- Standard and large phones (381px–650px)
- Tablets and compact laptops (651px–900px)
- Desktop layouts above 900px

Updates include a collapsible tablet/mobile navigation menu, larger touch targets, single-column booking forms on phones, flexible hero content, safer text sizing for mobile form controls, reduced horizontal overflow, and reduced-motion support.

## Run locally

```bash
npm install
npm run dev
```

Use browser device emulation to check widths of 320px, 360px, 390px, 430px, 768px, and 900px. Also test the navigation menu and booking/contact forms on a real phone before deployment.
